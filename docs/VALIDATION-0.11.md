# MyTube 0.11.0 validation

Channel navigation now separates the active channel route from its parent sidebar label. Right from the Subscriptions label while viewing a channel enters that channel's grid without selecting Subscriptions. Channel intent activation cancels pending sidebar navigation and focuses the first loaded channel video. Back still returns to the subscriptions page.

Search results use a vertical three-column grid, with keyboard Up routing only on the first row. Down near the end appends another search batch without disabling loaded cards; new submissions scroll to the first result. Library uses the shared vertical video grid and preserves original-title resolution and sidebar navigation.

NewPipe audio metadata owns track identity, locale, original/dub classification and display names. Automatic selection prefers an explicit ORIGINAL track before bitrate/format preferences; an explicit user choice takes priority. Choices reset per video. Audio language appears in the player settings drawer, including an original automatic option. Progressive video-only sources are paired with the chosen audio URI, rather than implicitly selecting the device-language dub from an HLS manifest. HLS fallback uses the identified preferred audio language. Switching calls the existing reconfiguration path, preserving position/play state, captions and speed. No new library schema or preference migration is introduced.

Source metadata was checked on the public Python course `https://www.youtube.com/watch?v=rfscVS0vtbw`: NewPipe returned original English (`en.4`) and Arabic, Spanish, Hindi and Portuguese alternatives. A local regression verifies original audio wins over a higher-bitrate dub, explicit dubbing selection wins over the default and a stale selection falls back to original. Unknown upstream original-language metadata remains unknown; the app cannot supply unavailable alternate tracks.

Executed checks and packaging are recorded in `artifacts/validation/0.11/`. The initial device run passed channel-intent entry/row navigation, original-English extraction/selection and real chapter-video playback. Its vertical search check incorrectly waited for an offscreen second-row node before pressing Down; the rerun waits for the first row and then exercises actual remote navigation. The final rerun passed both vertical Search/Library navigation and real player/chapter/audio-drawer checks (65.938 seconds). The drawer test selected an alternate track, checked preserved position and returned to original automatic audio. Local unit tests, debug/release lint and both APK builds passed (`build.txt`); unit counts are in `artifacts/unit-test-summary.json`. Earlier screenshots remain accurately labeled as 0.10.0; they were not regenerated for this update.

Packaging uses the existing local development key and in-place installation; schema remains 5. The optimized APK and debug APK are under `artifacts/`, with hashes in `SHA256SUMS` and `build-info.json`. No public release or GitHub publication was performed.
